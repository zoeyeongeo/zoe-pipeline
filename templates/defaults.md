# 기본값 표

질문하지 않은 빈칸을 채울 때 쓰는 기본값 (W-002, W-003). 쓴 경우 반드시 가정 목록에 남긴다.

| 빈칸 종류 | 기본값 | 되돌리기 비용 |
|---|---|---|
| 수치 (데미지, 시간, 속도) | SO 또는 인스펙터 노출 필드 + 임시값 (C-012) | 낮음 |
| 입력 | 프로젝트의 기존 입력 방식 그대로 | 낮음 |
| 연출 (이펙트, 사운드, 카메라) | 이벤트 훅만 만들고 실제 연출은 비워 둠 | 낮음 |
| 순수 로직 | EditMode 테스트 동반 | 낮음 |
| 이름 | 프로젝트 명명 관례 (C-001) | 낮음 |
| 내부 구조 | 기존 비슷한 시스템의 구조를 따름 | 중간 |
| **세이브 데이터 형식** | 기본값 없음 → 질문 | 높음 |
| **다른 시스템의 공개 API** | 기본값 없음 → 질문 | 높음 |
| **게임 규칙 (기획 판단)** | 기본값 없음 → 질문 | 높음 |
