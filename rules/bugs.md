# 리뷰 버그 패턴 (B)

> 리뷰에서 반복해서 나온 버그 모양. 스타일이 아니라 동작이 틀리는 것이라 모두 MUST.
> 출처: RPG 기준선(`metrics/baseline-rpg.csv`)의 UNMAPPED 중 두 번 이상 나온 것.

### B-001 bool 조건·값의 방향을 확인한다
- 심각도: MUST
- 규칙: bool로 켜고 끄는 값(`isKinematic`, `enabled`, 일시 정지 인자 등)과 `!`가 붙거나 빠질 수 있는 조건은 "참일 때 무슨 일이 일어나는가"를 한 문장으로 말해 보고 코드와 맞춘다. 리뷰는 이런 줄마다 참·거짓 두 경우를 따라가 본다
- 이유: 반전된 bool은 컴파일도 되고 에러도 없이 정반대로 동작해서, 플레이 전까지 드러나지 않는다
- 강제: 문서 → 리뷰
- 예외: 없음
- 출처: RPG 기준선 UNMAPPED 3건 (8단계 `!` 누락, 6번 줍기 `isKinematic` 반대, Y15 `OnApplicationPause` 반대)

### B-002 거리 비교는 기준 하나로
- 심각도: MUST
- 규칙: 같은 대상들 사이의 거리를 여러 곳(추적·정지·공격 판정 등)에서 비교하면 같은 헬퍼 하나를 쓴다. 제곱 거리(`sqrMagnitude`)는 제곱한 기준값과 비교하고, 평면(XZ)인지 3D인지와 경계(`<` / `>=`)를 모든 곳에서 맞춘다
- 이유: 기준이 어긋나면 "추적은 도착, 조건은 아직 추적"처럼 판정이 엇갈려 상태가 매 틱 바뀌거나 아예 시작되지 않는다
- 강제: 문서 → 리뷰
- 예외: 이동 방향처럼 거리 비교가 아니라 벡터 자체가 필요한 경우
- 출처: RPG 기준선 UNMAPPED 2건 (추적 `DetectRange` 비제곱 비교, 적 AI 5번 거리 기준 불일치)
